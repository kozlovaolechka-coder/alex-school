# Алекс Школа — согласованные требования

## Главный принцип
Лена не даёт Саше готовый ответ. Сначала объясняет правило простыми словами, затем задаёт один наводящий вопрос, ждёт ответ, локализует ошибку и ведёт дальше. После помощи — аналогичное самостоятельное задание и самопроверка. Маме доступны прямые ответы и подробная аналитика.

## Учебная модель
Три основные линии: Школа (синхронно с классом), Пробелы (ремонт слабых навыков), Развитие (логика/олимпиада после базы). Дополнительно «Опережение/Новая тема». Уровни ребёнка: зелёный — база, синий — уверенный, фиолетовый — продвинутый, кубок — чемпион. Карта знаний: 🟢 уверенно, 🟡 знает но ошибается, 🟠 частично, 🔴 пробел, ⭐ выше школы. Ошибка — место для прокачки; соревнование только с собственным прошлым результатом.

## Обязательные модули
Сегодня; Домашнее задание; Тренировка; Новая тема; Аудирование; фото тетради/страницы и проверка; кнопки «Лена, прочитай» и «Лена, помоги»; карта знаний; родительский дашборд; адаптивные короткие серии; скорость только после точности; логические/олимпиадные задачи после базы.

## Оценки и аналитика
Обязательная цепочка: ОЦЕНКА → конкретная работа → номера заданий → навыки → диагностическая тренировка → повторная проверка → изменение карты знаний. Оценка не красит навык автоматически. Причины определяются диагностикой: не понял правило / неверный алгоритм / вычислительная ошибка / невнимательность / устал или поспешил / недостаточная автоматизация / потребовалась помощь. Хранить предмет, дату, тип работы, источник, работу, страницы, номера, навыки, оценку, самостоятельность, подсказки, точность, время, первую и повторную попытки. Автоматизация: понимает → решает с Леной → самостоятельно → стабильно → в школьном темпе.

## Материалы Саши
Математика: Петерсон 3 класс, издание 2025 Саши; самостоятельные/контрольные Петерсон, углублённый уровень, вариант 1; «3000 примеров» точечно. Русский: Канакина/Горецкий 3 класс, Школа России, часть 1; словарные слова; проверочные/контрольные — вариант 1. Нельзя предполагать совпадение страниц разных изданий.

## Учебники пользователя
При добавлении учебника обязательны обложка и страница выходных данных: авторы, издательство, год, класс, часть/том, ISBN, издание/серия. Система определяет точное издание и просит подтверждение. Если найдено другое издание — явно сообщает и не считает номера страниц эквивалентными. Не превращать продукт в сервис распространения защищённых учебников; создавать собственные аналогичные тренировки.

## Профиль и будущая платформа
Сейчас: Саша, 3А. В будущем семейный аккаунт, несколько детей, роли родитель/ребёнок, отдельные учебники, школа, ДЗ, карта и история каждого ребёнка; строгая изоляция семей. Онбординг: ребёнок → класс → готовая программа или свои учебники → интересы/особенности → мягкая диагностика → карта → первый маршрут. Tablet-first, iPhone/Android/популярные планшеты.

## Родительский Telegram
В будущей версии: общий backend с сайтом; отправка фото ДЗ, чат с Леной о прогрессе, комментарии/коррекция карты знаний, загрузка учебников. Не отдельное хранилище.

## Данные и инфраструктура
Этап 1: GitHub → Cloudflare, постоянный сайт. Этап 2: существующий Supabase «Алекс Школа». Контрольный цикл: Саша решил → событие записалось в Supabase → мама/Лена может прочитать. Пока цикл не доказан end-to-end, не наращивать следующую инфраструктуру. Сейчас сайт сохраняет тестовое событие локально и помечает sync_status=local_waiting_for_supabase.

## Текущий учебный контекст
С/р №3: стр. 7–8 №1,2,5, оценка 2 — диагностика множеств/знаков, задачи в два действия и самостоятельного применения. Устный ответ по математике — 4; списывание по русскому — 4. «3000 примеров»: 5 минут, около 3 попыток с ошибками — сначала диагностика без таймера, затем автоматизация и только потом школьный темп.
